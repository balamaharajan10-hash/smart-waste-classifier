# Smart Waste Classifier

## Overview

Smart Waste Classifier is an AI-powered web application that identifies different types of waste from an uploaded image. The system uses a deep learning model to classify the waste and provides useful information about its recyclability, biodegradability, and appropriate disposal method.

The application is designed to make waste segregation easier and encourage responsible waste management.

## Features

- AI-based waste image classification
- Supports multiple waste categories
- Upload an image and get an instant prediction
- Displays waste category and classification result
- Provides recycling information
- Provides biodegradability information
- Suggests appropriate disposal methods
- Provides reuse information where applicable
- Simple and user-friendly web interface

## Waste Categories

The system can classify waste into the following categories:

- Battery
- Biological
- Cardboard
- Clothes
- Glass
- Metal
- Paper
- Plastic
- Shoes
- Trash
