About EcoSort AI

An AI decision-support tool for smarter waste sorting — how it works, and where it's limited.

How the model works

EcoSort AI uses transfer learning on MobileNetV2, a convolutional neural network (CNN) pretrained on ImageNet. Instead of training from scratch, we reuse its learned visual features and fine-tune a new classification head on our 10-class waste dataset. This gives strong accuracy with a small, fast, deployment-friendly model.

Each prediction ends in a softmax layer, which converts raw model outputs into a probability distribution across all 10 classes — that's where the confidence score comes from.

Model limitations

  • Predictions depend heavily on image quality, lighting, and framing.
  • Visually similar materials (e.g. certain plastics vs. glass) can be confused.
  • Some categories (like plastic type, or biodegradability of blended fabrics) truly require material composition information the model can't see.
  • Recyclability rules vary by location and local facility — always check local guidelines.
  • This is an AI decision-support tool, not a certified waste-sorting authority.

Key concepts (for the curious)

Transfer Learning
Reusing a model pretrained on a large dataset (ImageNet) and adapting it to a new, smaller task.
Data Augmentation
Randomly rotating, flipping, and shifting training images so the model generalizes better and doesn't just memorize the training set.
Confusion Matrix
A table showing which classes the model mixes up with which — used to diagnose weaknesses.
Precision / Recall / F1
Precision: of items predicted as class X, how many really are X. Recall: of all real class-X items, how many were found. F1 balances both.
Grad-CAM
A technique that highlights which regions of an image most influenced the model's decision — used here for explainability, not as proof of correctness.

Waste categories covered

Battery, Biological, Cardboard, Clothes, Glass, Metal, Paper, Plastic, Shoes, Trash — matching the structure of the public garbage-classification-v2 dataset.
